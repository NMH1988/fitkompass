### T11.17 A saved profile before redeeming a coach's invitation code (S) · status: in progress · issue NMH1988/fitkompass#37
**Serves:** Capstone (`docs/BRIEF_CAPSTONE.md`): E3 (ethical and privacy considerations: the app is for adults, and no coach's advice reaches a gymer who has not declared an adult age); beyond the brief (owner's request) for the feature itself. Sprint 3 (`docs/BRIEF_SPRINT3.md`): none; Sprint 2 (`docs/BRIEF.md`): none.
**Depends on:** T11.7 (order only: both change the Coach and sharing flow's docs and the PRD's "Before any real user" list)
**Acceptance criteria** (proposed by Claude and approved by the owner, 2026-11-24)
- [x] A gymer who has not saved a profile (whose first Save carries the 18+ check) cannot redeem a coach's invitation code: the store refuses it inside the redeem transaction (`invitations.accept_invitation()`), before the code is checked, with no relationship made, no attempt counted, and the code left valid - store tests.
- [x] The Coach and sharing page says to save the profile first, in English and German, with a way to open My profile - AppTest.
- [x] Nothing changes for the coach: their code stays valid and unused, and no notification or audit row is written - tests.
- [x] Relationships made before stay as they are; T11.7's page gates (the Meal plan page, the coach's target on My profile, My week) stay as a second layer; demo mode is unaffected - tests.
- [ ] `.claude/rules/security-privacy.md`, `docs/SECURITY.md` and the PRD's "Before any real user" sentence updated; `code-reviewer`, `compliance-reviewer`, and their reports on the PR.

**Notes:** the owner's request of 2026-11-24, from compliance round 2's decision on NMH1988/fitkompass#36: requiring a declared age before any coach relationship closes the gap for all three coach writes into a client's records (T9.17's targets, T9.34's suggested foods, T11.7's meal plan) at once, where T11.7 gated only what the gymer's pages show. A self-declared age is still no verification (the PRD's "Before any real user" list). Beyond the brief (owner's request); cut with the other extras if time runs short.
