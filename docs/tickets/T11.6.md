### T11.6 (P1) The coach's thread summaries and reply drafts (M) · status: todo · issue not yet created

**Depends on:** T11.5, O21
**Acceptance criteria** (proposed by Claude, 2026-11-19; for the owner's approval)
- [ ] On a thread, the coach asks for a summary of the week's messages or a reply draft; the draft is labelled as AI-generated in English and German and is sent only after the coach approves or edits it - graph tests with a fake model, AppTest.
- [ ] The thread (the coach's own messages included, as they can repeat the gymer's health data) reaches the model only with that gymer's consent (b) (`docs/PRD.md`, the Capstone's consents), which the gymer gives or withdraws in one click, stored with the version of its text and checked again right before each model call through T11.5's consent functions; consent (a), for their own drafts, does not count; without (b) the request is refused with a clear message and no model call (owner's choice, 2026-11-19) - tests, one with a fake model that is never called.
- [ ] Each message of the thread, from either side, and any text the coach types into the request (a hint for the reply, say), runs through the input guard and the domain guardrails before the model call, as in T11.5; a rejected message is left out of what the model receives (or the request is refused, as the Question phase sets), so an injury or injection message never reaches a model; when messages were left out, the draft says how many, without their text, and asks the coach to read them in the thread, as one may be an injury the coach must see - parametrised tests with a fake model that never receives a rejected message, AppTest of the note.
- [ ] No log line or trace holds a message, a summary or a draft - canary tests in `tests/test_observability.py` and a case in `tests/test_tracing.py`.
- [ ] Every Sprint 3 guardrail holds for a draft (no diagnosis, no program, the calorie floor in a recommendation, refused in code by the weekly review's checks where they apply) - tests reusing T9.16's and T10.2's checks.
- [ ] `docs/PRD.md` AC-50 holds; `code-reviewer`, `/security-review`, `compliance-reviewer`, and their reports on the PR.
