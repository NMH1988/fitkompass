### T11.10 (P1) A photo or a voice note to a draft log entry (L) · status: todo · issue not yet created
**Serves:** Capstone (`docs/BRIEF_CAPSTONE.md`): Case 4 step 1 (image and text analysis), Case 4 step 4 in part; Sprint 3 (`docs/BRIEF_SPRINT3.md`): none; Sprint 2 (`docs/BRIEF.md`): none.
**Depends on:** T11.5, O19
**Acceptance criteria** (proposed by Claude, 2026-11-19; for the owner's approval)
- [ ] The model (D29) is chosen in the Research phase, added to the model allowlist and built only with `build_chat_model()`; its licence and terms (input data, any condition on its output, its training data where `.claude/rules/copyright.md` rule 9 asks) are recorded in `docs/SOURCES.md` or `docs/ARCHITECTURE.md` with the owner's approval - review.
- [ ] Only with the gymer's consent (c) (`docs/PRD.md`, the Capstone's consents; its text names photos and voice notes, OpenRouter and this model's provider; stored with the version of its text and checked again right before each model call through T11.5's consent functions), a photo or a voice note within the size and type limits in config becomes a draft card through T11.5's checks; a file over the limit or of another type is refused before any model call - tests with a fake model.
- [ ] The steps run in this order: the size and type check; a first model call that only transcribes the voice note or describes the photo, with a fixed instruction and no profile, message or other data; then the input guard and the domain guardrails on that text, before T11.5's extraction; a rejected transcript or description makes no draft and no further model call - tests with a scripted fake model (an injury and an injection in the transcript among them). The first call is the one model call that no guard can check first, as the guard reads text: it is recorded as an exception in `.claude/rules/security-privacy.md` ("Guards") with the owner's decision, and as a known limit in `docs/SECURITY.md`.
- [ ] The file is read in memory only: nothing is written to disk, a log line or a trace, also while demo mode's unmasked traces are on (`tracing.demo_gate_open()`) - tests (a temp directory left empty, canary tests, a trace case with the gate open).
- [ ] A photo is re-encoded in memory (Pillow) without its metadata before it is sent - a test that a JPEG with a GPS tag leaves the app without it.
- [ ] Nothing is logged without the gymer's approval; the card is labelled as AI-generated - AppTest.
- [ ] `docs/PRD.md` AC-51 holds; `code-reviewer`, `/security-review` (a new input path to a model), `compliance-reviewer` (a new model provider and special category data in images and audio), and their reports on the PR.
